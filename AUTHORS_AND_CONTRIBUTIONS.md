# KylGis Kitchen Screen — authorship and upstream attribution

KylGis Kitchen Screen is the KylGis-branded continuation of Chromis Kitchen Screen and is distributed under the GNU General Public License v3 or later, consistent with the inherited source license.

## Upstream

The original Kitchen Screen codebase is credited to **John Lewis / Chromis** (2015). Original `@author` declarations and upstream attribution are retained in source files where applicable. KylGis does not claim authorship of inherited Chromis code.

## KylGis modifications

Modifications and integration work performed in 2026 for KylGis include namespace migration, KylGis POS database configuration integration, order grouping by `COMPLETETIME`, preservation of real product/auxiliary order, completion/recall fixes, startup configuration access and the KylGis rebranding.

The companion POS application is KylGis POS (`https://pos.kylgis.com`). KylGis POS itself descends from Openbravo/uniCenta/Chromis code and preserves their respective attribution in that repository.

## Historical compatibility identifiers

Some legacy names can remain intentionally in migration compatibility code or immutable database-migration history. Their presence does not represent current product branding. In particular, already-applied Liquibase change-set identifiers must not be renamed merely for branding.
